### Sobre mim

Hoje estou focado em terminar a faculdade e em construir projetos que valham a pena colocar no portfólio — não só exercícios de sala de aula. O **TaskForge** é o principal deles até agora: um gerenciador de tarefas full stack com Kanban, dashboard, autenticação e proteção contra brute-force, feito para resolver um problema real de organização, não só para cumprir um requisito.

Uso React no front e transito entre Node.js, Python e Java no back, dependendo do que o projeto pede. Estou buscando minha primeira oportunidade como desenvolvedor e, enquanto isso não chega, sigo aprendendo — a próxima frente é aprofundar em APIs REST e boas práticas de arquitetura.
